# 离线展示、证据回链与验收

## 一、交付结构

默认提供一个可双击打开的本地 HTML，内含：

1. 全景演化地图；
2. 三张研究空间热力图；
3. 单篇论文卡；
4. 中文或用户指定语言的全景调研报告入口。

同时保留 Markdown 报告、结构化 CSV 和展示快照。四种视图从同一 `snapshot_id` 生成，避免图、格、卡和报告各自使用不同版本。

## 二、展示输入与回链

| 产物 | 权威输入 | 回链要求 |
| --- | --- | --- |
| 演化地图 | Q/M 字典、paper_registry、evolution_edges、原始引文缓存和可选 MPA 输出 | 节点到论文卡，边到关系说明与原文定位 |
| 三张热力图 | 实验级配对、格子状态、定向补搜记录 | 格子到论文集合、experiment_id 和 evidence_id |
| 中文报告 | 已核关系、路线审计、结论和缺口 | 每项实质结论关联比较条件与原文；统计可回查分子、分母及构成记录 |
| 单篇论文卡 | 书目、双日期、8 类属性、骨干关系、实验结果和证据审计 | 主结论、限制、上下游、矩阵格和版本定位可互查 |

可访问的本地资料使用发布目录内相对路径；无本地副本时提供对应版本稳定链接和页、表、式定位。证据版本与登记主版本不同时分别标明。

## 三、全景演化地图

- Q、M、P 使用不同形状和可读图例；论文节点按首次公开日期与分支布局，日期精度不足时单独显示。
- 语义边用颜色或标签表示关系，线型表达证据强度，结果适用性在详情中显示。
- 平行发展使用无向样式，不把存储端点顺序画成继承箭头。
- 默认加载 Q/M 骨架和已核语义边；原始引文与 MPA 默认关闭，可按节点或分支展开。
- 反驳或边界修正打开后显示被修正的具体主张及实验条件。
- 可按分支、年代、目标、节点类别、关系和证据强度筛选，显示当前范围与条目数。
- 点论文打开论文卡，点边显示关系、参与论文、证据定位和条件；候选边默认收起且不计入已核实证统计。
- 提供可键盘访问、可按 ID 查找的节点与边清单。

## 四、三张热力图

- 格内数字为去重 `paper_id` 数，同篇多格命中时另报矩阵命中和论文去重总数。
- 格子状态包括“已有覆盖”“待核”“定向查找后在所查范围内未发现”。
- 每个格子可展开论文、实验配对和证据定位；定向查找状态附查询、来源、窗口和截止日。
- 筛选只改变当前可见计数，不覆盖完整快照中的原始格子状态。
- 用户可核实方法是否实际运行、变量在对应实验中是目标、输入、控制还是基线。

## 五、中文报告与论文卡

报告至少包含：路线总览、分路线演进、共识与争议、负面结果、研究空白和待核线索。历史驱动因素注明出处或推断属性，CER/成本、PIT/泄漏和其他领域特定证据按实际条件呈现。

论文卡包括：

- 题名、作者、来源、双日期、版本、通道和纳入状态；
- 8 类属性与对应实验；
- 路线位置、上游/下游关系和所属矩阵格；
- 按对象、目标、期限、样本、模型、基线和指标区分的结果；
- 证据状态、主要支持、失效条件和原文定位；
- 仅有摘要时的证据上限。

## 六、离线与性能验收

1. **对账**：节点、边、矩阵格、论文集合、状态和证据与展示快照一致；抽取变量角色、跨实验差异、边界修正和版本差实例回查。
2. **断网检查**：双击 HTML 可打开，分支筛选、节点/边详情、矩阵点查、论文卡展开和返查可用；Markdown 可独立阅读并保留可读表格。
3. **性能**：使用接近正式规模的数据检查布局与交互。若单文件超过 15MB 或实测明显卡顿，提供“轻量主包单文件＋全量归档包”，按需加载原始引文、MPA 和大块实验数据。
4. **重建**：从同一展示快照重新生成结构化数据和展示文件，确认没有手工补边、补格或补写结论。

轻量主包可以减少首屏数据，但不得删除全量归档中的原始证据、实验配对和回链。
