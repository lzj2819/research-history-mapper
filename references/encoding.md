# 属性、矩阵与演化关系编码

## 8 类研究属性

| 属性 | 要回答的问题 | 通用示例 |
| --- | --- | --- |
| 1. 研究问题与任务 | 论文主要解决什么问题？ | 理论构建、测度、预测、机制解释、方法比较、数据集、应用 |
| 2. 研究目标及定义 | 被解释、预测或构造的对象是什么？ | 数学目标、概念口径、方向/水平、连续/跳跃、风险或分类标签 |
| 3. 信息与数据来源 | 使用了哪些原始或派生信息？ | 文本、实验、观测、调查、官方数据、商业数据库、派生指数 |
| 4. 表示与操作化 | 如何把信息变成可分析变量？ | 指标、词典、主题、嵌入、事件、量表、实验测量、特征工程 |
| 5. 方法与模型 | 如何从输入映射到目标？ | 计量模型、统计学习、机器学习、深度学习、仿真、实验或混合设计 |
| 6. 机制与理论解释 | 为什么会产生该结果？ | 因果机制、行为机制、供需、制度、认知、物理或社会过程 |
| 7. 实验与数据协议 | 结论在什么条件下测得？ | 样本、频率、期限、滚动/递归、时间对齐、对照、数据版本 |
| 8. 证据与评价标准 | 用什么证据支持结论？ | 统计损失、显著性、稳健性、消融、经济价值、复现、案例证据 |

主类按主要研究产出判定。辅助方法、比较基线和稳健性分析不得挤占主类。对“未报告”区分未找到披露、明确未做、待核和不适用。

## 角色分离

至少分别保存：

- `research_targets`：被解释、预测或构造的对象。
- `input_variables`：实际进入模型或分析的信息。
- `controls`：用于减少混杂或替代解释的变量。
- `baselines`：用于比较的其他方法或规格。

同一变量在不同实验中的角色可以不同，必须按对应实验或结果记录，而不是按变量名称永久归类。

## 矩阵规则

### A：研究问题 × 方法家族

任务与实际执行的方法配对。混合模型按主要产出和架构归类，基线中仅出现的方法不冒充论文主方法。

### B：研究目标 × 信息类型

目标与实际输入必须在同一实验或结果中配对。控制变量、比较基线和预测目标分别保留。

### C：历史时期 × 研究分支

以首次可证实公开日期落入冻结时期，以证据认定分支。日期精度不足时保留待核，不为了填满矩阵猜日期。

每格以唯一 `paper_id` 计数；同一论文可因不同有据配对出现在多个格子，汇总时另报去重论文数。

## 节点类型

- `Q`：研究问题节点。
- `M`：方法、核心概念、机制、指标口径或评测协议节点。
- `P`：单篇研究证据节点。

概念骨架与实证边分开。研究时间继承子图保持有向无环，整体概念网络可以包含问题依赖与反馈。

## 合法关系

| 起点→终点 | 关系示例 |
| --- | --- |
| Q→Q | 问题分解、问题扩展、问题重定义 |
| Q→M | 对应解决方法或概念 |
| M→M | 技术扩展、方法融合、方法替代候选 |
| P→Q | 提出问题、研究或检验问题 |
| P→M | 首次提出、采用或实现、评估或批判 |
| P→P | 直接改进、方法复用、跨路线融合、实验基线比较、反驳或边界修正、平行发展 |

## P→P 方向契约

除平行发展外：

- `source_id` 是较早或被作用的基准工作。
- `target_id` 是较晚或主动实施关系的工作。

按被动/演进语义读取：source 被 target 直接改进；source 的方法被 target 复用；source 的路线被 target 用于融合；source 被 target 用作基线；source 的具体主张被 target 反驳或作边界修正。

不要把新论文按主动句式写入 source，也不要把“实验基线比较”误读成方法继承。

`平行发展` 按 `min(paper_id) → max(paper_id)` 规范化存储，在比较和展示时视为无向关系，不进入时间 DAG。

严格时间与环路检查只用于直接改进、方法复用和跨路线融合。两篇仅知同年时允许相等，但需要明确单向引用与正文继承证据；明确倒置或无法解序的关系保留候选。

## 每条边的证据字段

建议至少保存：

- `edge_id`：`SKxxx` 表示概念骨架、`Exxx` 表示已核语义边、`CExxx` 表示候选边、`CITxxx` 表示原始引文边；完整 ID 不得跨层碰撞。
- `source_id`、`target_id`。
- `relation_type`。
- `evidence_paper_id`。
- `evidence_ids`：一个或多个原文证据记录，直接连接实验级缓存。
- `evidence_locator`：章节、物理页/刊页、公式、表格及必要的行列。
- `evidence_strength`：强（公式/代码/同口径实验）、中（正文声明与引用语境）、弱（间接关联或分析推断）。
- `outcome_validity`：报告条件下支持、条件依赖、证据不足、结论冲突或不适用。
- `controversy_note`：目标、样本、任务、期限或对照差异。

弱推断不混入已核事实边。声称“首次提出”时同时给出实际查证范围。
